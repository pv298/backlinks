# Backlink & SEO Resource Hub

A public collection of practical SEO resources, digital marketing references, checklists and learning materials maintained by **FSIDM — Full Stack Institute of Digital Marketing**.

The goal is to publish useful material that educators, students, founders, marketers and website owners can reference. This repository is not a link farm, paid-link list or automated backlink scheme.

## Official websites
- **FSIDM:** https://fsidm.in/ — digital marketing education and training.
- **Pranav Veerani:** https://pranavveerani.com/ — digital growth consulting and professional profile.

These links identify the maintainers and provide context for the resources. A link in this repository does not guarantee search-engine ranking improvements.

## Principles
1. Publish original, useful and verifiable information.
2. Link to sources when making factual claims.
3. Recommend tools or services only when relevant; disclose affiliations where applicable.
4. Do not submit spam, scraped lists, hidden links, keyword-stuffed anchors or paid-link schemes.
5. Keep resources current and correct outdated information.
