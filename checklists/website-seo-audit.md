# Website SEO Audit Checklist

Use this checklist as a repeatable starting point. Not every item applies to every website.

## Discovery and measurement
- [ ] Confirm the site's goals and priority pages.
- [ ] Confirm Google Search Console access.
- [ ] Confirm analytics measurement is configured appropriately.
- [ ] Record a baseline for organic clicks, impressions and conversions.

## Technical SEO
- [ ] Important pages return the intended HTTP status.
- [ ] Robots.txt does not block important content unintentionally.
- [ ] Important pages are not accidentally marked noindex.
- [ ] Canonical tags point to preferred URLs.
- [ ] XML sitemap contains relevant canonical URLs.
- [ ] Redirects are intentional and avoid unnecessary chains.
- [ ] HTTPS and preferred host redirects work consistently.
- [ ] Mobile layout is usable.
- [ ] Performance issues are reviewed.

## On-page SEO
- [ ] Each important page has a descriptive title.
- [ ] Main heading clearly describes the page.
- [ ] Content addresses the visitor's intent.
- [ ] Headings organize the page logically.
- [ ] Internal links use descriptive anchor text.
- [ ] Images have appropriate alternative text where useful.
- [ ] Structured data is accurate and eligible.

## Content quality
- [ ] Content is accurate and up to date.
- [ ] Claims are supported by reliable sources.
- [ ] Pages provide distinct value.
- [ ] Duplicate or overlapping pages are reviewed.
- [ ] Contact, author or organization information is clear where relevant.

## Off-page and reputation
- [ ] Relevant brand mentions are monitored.
- [ ] External links are reviewed for relevance and context.
- [ ] No paid or automated link schemes are used.
- [ ] Outreach is personalized and offers a genuine resource or collaboration.

## Follow-up
- [ ] Issues are prioritized by impact and effort.
- [ ] Owners and deadlines are assigned.
- [ ] Changes are documented.
- [ ] Results are reviewed after an appropriate period.
