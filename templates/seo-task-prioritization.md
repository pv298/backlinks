# SEO Task Prioritization Template

Use one row per issue or opportunity. Estimate impact and effort using your own project context; these ratings are not universal.

| Task | Page or URL | Evidence | Expected user benefit | Impact (low/med/high) | Effort (low/med/high) | Owner | Status |
|---|---|---|---|---|---|---|---|
| Example: improve page title | https://example.com/page | Search Console / review | Clearer page description | Medium | Low | Name | Not started |

## Review questions
1. Does the task solve a real user or site problem?
2. What evidence supports doing it?
3. Could the change harm accessibility, usability or content accuracy?
4. How will the outcome be measured?
5. When should the result be reviewed?
