# Writing Useful Title Tags and Meta Descriptions

Title tags and meta descriptions help describe a page. They should be written for people first and accurately represent the page content.

## Title tag checklist
- Describe the page's main topic clearly.
- Make the title distinct from other pages on the same site.
- Put the most useful identifying information first.
- Avoid repetitive keyword lists and boilerplate.
- Keep the title consistent with the visible page heading and content.
- Review how the title appears in search results; search engines may generate a different title link.

## Meta description checklist
- Summarize the actual page, not the whole website.
- Explain what a visitor can expect to find.
- Make important differences or benefits clear without exaggeration.
- Write a unique description for important pages.
- Avoid keyword stuffing and generic repeated descriptions.

There is no guaranteed character count that ensures a title or description will display exactly as written. Search-result presentation can vary by device, query and search engine.

## Simple working template
**Title:** [Main topic] | [Brand or site]

**Description:** [What the page helps the reader do] + [specific supporting detail]

Use the template as a starting point, not a rigid formula.
