# A Practical SEO Audit Workflow

An SEO audit is a structured review of a website's discoverability, technical accessibility, content and user experience. This workflow is an educational starting point; adapt it to the site's platform, size and goals.

## 1. Confirm the objective
Identify the website's primary audience, important pages, target markets and business outcomes. Record the pages that matter most before reviewing individual SEO elements.

## 2. Check crawlability and indexability
- Review the robots.txt file.
- Check that important pages return an appropriate HTTP status.
- Inspect canonical tags for key pages.
- Review XML sitemaps and confirm they contain preferred, indexable URLs.
- Look for accidental noindex directives or blocked resources.
- Use Google Search Console to inspect representative URLs and indexing reports.

## 3. Review page-level content
- Give each important page a clear, descriptive title.
- Write a useful meta description that accurately reflects the page.
- Use headings to organize the content logically.
- Make the page satisfy the searcher's likely intent.
- Add descriptive internal links to related pages.
- Use meaningful image alt text when images convey information.

## 4. Review technical experience
- Test mobile usability and responsive layouts.
- Check loading performance and Core Web Vitals.
- Fix broken internal links and redirect chains.
- Use HTTPS and maintain consistent preferred URL versions.
- Add structured data only when the page genuinely qualifies.

## 5. Review content quality
Look for missing information, duplication, outdated claims and pages that do not offer a clear user benefit. Improve or consolidate weak pages instead of publishing more pages solely to target keywords.

## 6. Review authority and references
Evaluate whether relevant websites naturally reference the business or its useful resources. Prioritize editorial relevance, audience fit and trust. Avoid buying links, automated submissions and irrelevant link exchanges.

## 7. Prioritize and measure
Create a task list with impact, effort, owner and status. Record a baseline before making changes, then monitor Search Console, analytics and business outcomes over time.
