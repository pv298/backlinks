# Full-Stack Marketing Agent Skills

Reusable, task-focused agent skills for planning, executing and reviewing digital marketing work.

These skills use the open Agent Skills folder convention: each skill lives in its own directory and contains a `SKILL.md` file. They are written to be useful with compatible agent environments; actual tool access depends on the host platform and the user's permissions.

## Skills

| Skill | Use it for |
|---|---|
| [Marketing strategy](marketing-strategy/SKILL.md) | Research, positioning, audience and go-to-market plans |
| [SEO & AEO](seo-aeo/SKILL.md) | Technical, on-page, off-page, local SEO and answer visibility |
| [Content marketing](content-marketing/SKILL.md) | Editorial strategy, briefs, blogs and repurposing |
| [Paid advertising](paid-advertising/SKILL.md) | Google and Meta campaign planning and optimization |
| [Social media](social-media/SKILL.md) | Channel strategy, calendars, posts and short-form video |
| [Email & automation](email-automation/SKILL.md) | Lifecycle email, lead nurturing and workflow design |
| [Conversion optimization](conversion-optimization/SKILL.md) | Landing pages, funnels, CRO hypotheses and experiments |
| [Marketing analytics](marketing-analytics/SKILL.md) | Measurement plans, reporting and performance diagnosis |

## How to use

1. Open the skill relevant to the task.
2. Provide the agent with the business context, target audience, offer, market, constraints and available data.
3. Ask it to follow the skill's workflow and return the specified deliverables.
4. Review recommendations before publishing, spending budget or changing live systems.

## Quality principles

- Never invent performance data, customer quotes, research findings, certifications or product claims.
- Separate observed facts, assumptions and recommendations.
- Cite sources for external claims and note when research is incomplete.
- Respect platform policies, privacy, consent and applicable advertising rules.
- Do not launch campaigns, send messages or modify live assets without explicit approval.
- Optimize for qualified business outcomes, not vanity metrics alone.
